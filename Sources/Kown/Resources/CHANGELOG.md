## 0.32.4 — 2026-06-15

## 0.32.0 — 2026-06-13
### 新增
- **个人口味路由 + 盲测** — 同一问题让两个模型匿名出答案、你来盲选谁更好,Kown 按任务类别(问答/写作/代码/分析)悄悄积累一份**只属于你的**模型偏好;开启后 Direct 模式会优先按你的口味选模型(附理由角标),而不是只看难度和价格。入口在「设置 ▸ 模型路由」,可随时盲测加样本
- **分歧雷达** — 多模型回答后一键「只看分歧」:不再让你对着两大段答案自己找不同,而是直接列出各家在哪几点上分歧、谁站哪边、理由是什么,共识部分折叠。高风险决策(选型/医疗/投资)最该先看「它们在哪儿不一致」
- **红队压测** — 任意一条答案都能点「红队压测」:指定一个对手模型专门挑它的幻觉、最弱论断、没给出处的数据,原模型再逐条辩护或当场改口。想知道「这个答案靠不靠谱」时,比再问一遍更狠
- **接力精炼(跨厂商流水线)** — Direct 模式新增「接力」:模型 A 起草 → 换一家模型 B 批判改写 → 再换一家润色定稿,每一棒可指定不同模型,扬长避短地把一个答案磨好,各阶段产物都看得到
- **实时屏幕副驾(macOS)** — 看网课、读论文、对方共享屏幕时开启,Kown 节流地看你的屏幕并本地 OCR 成滚动文本,你随口问「刚那页讲了啥」「总结我刚读的」。全程本机识别、不上传、不落盘,开着有醒目「正在看屏幕」提示,关掉即停
- **日历到点自动开会(macOS)** — 监听日历里的会议,到点提示(或自动)开启双轨会议捕获,结束把 AI 纪要写回这条日历事件的备注,零手动操作就有会议记录
- **语音随手记** — 走路、通勤时对着手机口述,实时转写成文字、AI 自动按主题打标后存进知识库,以后能被语义召回。一个会自己归档的「声音备忘」
- **对话树画布** — 把会话的分支血缘铺成一张可缩放的树:一条思路怎么分叉、每个岔路通向哪一目了然,点节点直接跳过去。探索多种解法时不再淹没在线性历史里
- **知识图谱** — 自动发现知识库条目、历史对话、长期记忆之间的暗线并画成图谱,「这条和你三周前讨论的某事相关」一眼可见;相似度阈值可调、可重新发现。入口在侧栏
- **订阅任务趋势洞察** — 定时 Agent 任务现在会留存历次报告的历史序列,可生成**走势**洞察(盯一件事几周看趋势,而不是每天孤立快照);任务卡有历史时显示「走势」入口
- **AI 现做交互小工具** — 让 AI 为当前问题临时造一个**能用的**交互式小工具(可筛选的数据表、可调参的计算器/图表),而且工具里的操作能回调模型再回填结果——超越静态预览图的「生成式 UI」。答卡点「生成交互工具」即可,改也能让 AI 改

### 修复
- **「安装并重启」按钮无效、要手动退出才更新** — 进程级抓包确认:点按钮后 Sparkle 的安装器(`Autoupdate` / `Updater.app`)起来了,但 Kown 进程没退出,安装器就一直死等。根因:Sparkle 因后台更新检查未声明 gentle reminders,把 Kown 当 background app,不替它终止进程。修复:UpdaterService 实现 `SPUStandardUserDriverDelegate`(声明支持 gentle reminders,让 Sparkle 走前台「终止并重启」流程)+ `SPUUpdaterDelegate.updaterWillRelaunchApplication` 兜底强制 `terminate`。注:本修复在新版本生效——升到 0.6.16 之后,之后的更新点按钮即可自动重启

## 0.6.13 — 2026-05-29

- **自动更新无限循环 /「安装并重启」不生效** — 之前每个发布的包 `CFBundleVersion` 都被硬编码成 `1`,而 appcast 的 `sparkle:version` 用 git 提交数(单调递增)。装好新版后 app 仍报 build 1,Sparkle 一比 `8 > 1` 又弹更新,点安装重启后还是 build 1 → 死循环。现在 `CFBundleVersion` 走 `$(CURRENT_PROJECT_VERSION)`,由 CI 注入 git 提交数,和 appcast 对齐,Sparkle 正确识别"已是最新"
