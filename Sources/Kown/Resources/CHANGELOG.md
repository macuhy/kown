# 更新日志

## 0.19.0 — 2026-06-06
### 新增
- **GitHub 改文件前先读现状** — 连接 GitHub 仓库后,让模型改已有文件时它会先读到该文件的当前内容(并能看到仓库文件树),在此基础上修改再提交,而不是凭空重写覆盖原有内容。新建文件不受影响,改动更稳更准
### 改进
- **设置页按分组组织** — 设置侧栏从一长串扁平列表改成「基础 / 工作流 / 数据 / 洞察 / 版本」分组,更好找
- **会话侧栏顶部重做** — 顶部显示当前模式与会话 / 文件夹计数,新建文件夹 / 会话按钮统一样式
### 修复
- **GitHub 连接验证码弹窗** — 在设置页点「连接」后,验证码现在直接在设置卡片里就地显示(此前要先关掉设置窗口才出现、且没有取消入口);点「取消」会真正终止后台授权轮询,不再留下僵尸请求

### 改进
- **设置页更紧凑清晰** — 设备工具页新增状态总览、授权说明和使用提示;GitHub 与技能页增加自适应标题、操作区和错误展示,减少大块空白
- **iOS 输入栏上下文更明确** — 「更多」菜单可直接切换设备工具、技能和 GitHub 仓库;已启用的设备工具 / 技能 / GitHub 仓库会在输入栏上方显示可移除的状态 chip

## 0.18.0 — 2026-06-06
### 新增
- **连接 GitHub,把定稿直接提交到仓库** — 在「设置 ▸ GitHub」用设备码登录(浏览器输入一串验证码即可完成授权,不用手动生成 / 粘贴 token)。连接后在对话输入栏点「选仓库」选一个目标仓库,让模型把整理好的内容写进文件,系统会自动提交到该仓库,并在聊天里显示每个文件的改动行数(+N / −M)和 commit 链接。iOS / macOS 均可用
### 修复
- **新版 Claude 模型设了温度就报错** — 部分新模型已弃用 `temperature` / `top_p` 参数,带上会让请求直接失败(追问建议、正常回答都可能报「temperature is deprecated」)。现在遇到这类报错会自动去掉采样参数重试一次,不再中断对话
### 维护
- **命令行 Provider 支持温度占位符** — CLI 模型的参数模板新增 `{temperature}` 占位符,可把温度值传给支持该参数的命令行工具

## 0.17.0 — 2026-06-06
### 新增
- **技能(Skills)** — 把「人设 + 可用工具」打包成一个技能:写一段系统提示(支持 `{{变量}}`)、勾选它能用哪些工具(联网 / 提醒 / 备忘录)。命中关键词时自动启用,也能在输入栏手动绑定到当前会话。内置「提醒助手 / 备忘记录 / 研究助手 / 翻译官」四个开箱即用预设(设置 ▸ 技能)
- **操作系统「提醒事项」** — 模型可在对话里直接帮你创建提醒(自动把「明天 9 点 / 下周一」换算成具体时间并挂到点闹钟),也能查看你未完成的待办。iOS / macOS 均原生支持,首次使用会请求授权
- **操作系统「备忘录」** — 让模型把整理好的内容写进备忘录:macOS 通过自动化直接新建(首次弹授权框);iOS 没有公开写入接口,会把内容复制到剪贴板并打开备忘录 App 供你粘贴
- **答卡一键存到设备** — 每条回答下方的「保存」菜单可把该回答直接「存为提醒 / 存为备忘」,不必再经模型
- **设备工具开关** — 输入栏新增「设备工具」按钮,本次发送是否开放提醒/备忘录工具由你掌控(设置 ▸ 设备工具 可查看授权状态与平台说明)
### 维护
- **工具调用上下文重构** — 把工具运行时上下文从「仅联网」泛化,联网关闭时设备工具也能独立工作;新增技能路由、工具组合、时间解析等单元测试

- **搜索更顺滑** — 侧栏与命令面板搜索改为每次按键只检索一次、结果按需截断,海量会话下输入不再卡

## 0.16.0 — 2026-06-06
### 新增
- **模型擂台 / 淘汰赛模式** — 新会话模式:所有启用的模型先各自作答,再由裁判逐对捉对厮杀、层层晋级,最后决出「冠军答案」,看哪家在你的问题上真正最强
- **对比裁判 + 模型胜率榜** — Compare 两家作答后点「让裁判评判」选出胜者并给理由;胜负长期累计成「排行榜」(设置 ▸ 排行榜),一眼看出哪个模型对你最好用
- **答案差异分析** — Compare / Council 里点「分析分歧」,自动把各家回答归纳成「共識(都同意)/ 分歧(意见不一)」两栏,省去逐字对比
- **结构化输出模式** — 定义一份 JSON Schema,强制每个模型只返回严格 JSON,并自动校验、并排对比各家结果(内置优缺点评分 / 实体抽取 / 任务分解 / 情感分析等预设)
- **对比仪表盘** — 设置 ▸ 仪表盘 用图表展示各模型的成本排行、每日 token 走势与输入/输出内訳,成本一目了然
- **跨会话长期记忆** — 可选开启(默认关,隐私优先):自动从对话里抽取长期事实/偏好,发送时按相关度注入新会话的上下文
- **批量执行 / 提示词队列** — 多个问题一次性投给多个模型,矩阵表对比结果,支持导出 CSV / Markdown,适合夜间跑批或横评
- **评测台(回归)** — 保存一组(问题 + 期望)用例,版本更新后一键重跑各模型,快速发现「模型漂移」
- **链式工作流** — 把多步串起来(如 草稿 → 批评 → 修订),用 `{{prev}}` / `{{input}}` 把上一步输出喂给下一步
- **提示词润色** — 输入框一键让小模型把你的提问改写得更清晰具体,满意再采用
- **图像扫描 OCR(iOS)** — 拍照 / 选图后识别其中文字,直接追加到输入框
- **图像生成对比** — Direct 模式让多个出图模型用同一提示词并排出图比较
- **菜单栏剪贴板助手(macOS)** — 菜单栏面板里对剪贴板内容一键「翻译 / 总结 / 解释」并复制结果
- **定时任务** — 设置 ▸ 定时任务,让指定提问每天定点自动执行(应用运行中触发)并本地通知
- **内置提示词模板** — Prompt 库新增 25 条常用中文模板(翻译 / 校对 / 代码审查 / SQL / 学习计划 / 决策分析等),带 `{{变量}}` 占位
### 改进
- **追问建议失败有原因可看** — 「追问建议」生成失败时,直接显示具体原因(没有可用模型 / 当前轮无回答 / 调用出错等),不再静默无反应
### 修复
- **中文条目首字不再被吞** — 修复「差异分析」里以「一致 / 二者」等中文数字开头的条目被误当成列表序号、首字被删的问题
### 维护
- **新增单元测试** — 为结构化输出、擂台裁判、差异分析、链式填充、Turn 存档兼容等核心逻辑补充单元测试
- **检索 / 工作区扫描移出主线程** — 知识库检索与工作区文件扫描改为后台执行,大知识库下发送不再卡顿

## 0.6.16 — 2026-05-29
### 修复
- **「安装并重启」按钮无效、要手动退出才更新** — 进程级抓包确认:点按钮后 Sparkle 的安装器(`Autoupdate` / `Updater.app`)起来了,但 Kown 进程没退出,安装器就一直死等。根因:Sparkle 因后台更新检查未声明 gentle reminders,把 Kown 当 background app,不替它终止进程。修复:UpdaterService 实现 `SPUStandardUserDriverDelegate`(声明支持 gentle reminders,让 Sparkle 走前台「终止并重启」流程)+ `SPUUpdaterDelegate.updaterWillRelaunchApplication` 兜底强制 `terminate`。注:本修复在新版本生效——升到 0.6.16 之后,之后的更新点按钮即可自动重启

## 0.6.15 — 2026-05-29
### 改进
- **每次打开 App 都做一次后台静默更新检查** — 之前只靠 Sparkle 的每日定时器(`SUScheduledCheckInterval=86400`),距上次检查不满 24h 就不查,所以新版发出来后不会马上发现。现在启动时额外强制一次 `checkForUpdatesInBackground`(尊重"自动检查"开关):开了自动下载就静默装、下次启动生效,否则弹更新窗

## 0.6.14 — 2026-05-29
### 修复(严重)
- **iCloud 迁移卡死 + 冲突副本根治** — `copyTree` 之前用裸 `FileManager.copyItem` 直接读写 iCloud 容器:读云端 placeholder 会同步阻塞等 materialize(FileProvider 忙时整迁移卡死在某个文件上 100% 不动),未协调的写入又让 iCloud 把同名文件 fork 成 `.kown 2/3/4...`(那上千个冲突文件的来源)。现在每个文件走 `NSFileCoordinator` 协调读写 —— 读端先把云文件拉下来再交付,写端拿独占 slot 再落盘,既不会无限卡,也不再生成冲突副本。migrate / mirror / reconcile 三条路径都受益

## 0.6.13 — 2026-05-29
### 修复(严重)
- **自动更新无限循环 /「安装并重启」不生效** — 之前每个发布的包 `CFBundleVersion` 都被硬编码成 `1`,而 appcast 的 `sparkle:version` 用 git 提交数(单调递增)。装好新版后 app 仍报 build 1,Sparkle 一比 `8 > 1` 又弹更新,点安装重启后还是 build 1 → 死循环。现在 `CFBundleVersion` 走 `$(CURRENT_PROJECT_VERSION)`,由 CI 注入 git 提交数,和 appcast 对齐,Sparkle 正确识别"已是最新"
### 修复
- **侧边栏会话列表大片空白 / 重复** — iCloud 冲突会生成「`<id> 2.json`」副本,`loadAll` 把同一个 id 读成多份,SwiftUI `ForEach` 拿到重复 Identifiable id 导致布局错乱。现在按 id 去重,保留 `updatedAt` 最新的一份
### 改进
- **设置顶部 tab 放不下文字时自动只显示图标**(`ViewThatFits`)— 标签宽度不够不再挤成两行,退化成纯图标 + tooltip
