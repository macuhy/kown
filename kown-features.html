Kown 功能总览

一个 macOS + iOS 的多模型 AI 工作台 —— 同一个问题,让多个模型一起答、并排比、互相辩,再把结果沉淀成研究、会议与交付物。

4 种对话模式 OpenAI 兼容 · Claude · Gemini · CLI 联网 · 知识库 · 视觉 · 出图 深度研究 · Agent · 交付物 AI 待办 · 流程模板 · 记忆审计 可信度 · 模型体检 · MCP iCloud 同步 · 双端

核心 · 多模型协作

🧠

议会 Council

多脑同答 + 主席综合

  • 所有启用的模型各自作答
  • 主席模型再做一轮综合
  • 可选投票打分:准确 / 完整 / 可执行 / 清晰四维排名
💬

直接 Direct

专注单模型

  • 跟一个模型一对一对话
  • 可按难度自动选档(便宜↔旗舰)
  • 答卡随时换模型续聊
⚖️

对比 Compare

并排看差异

  • 同一问题发给两个模型
  • 左右并排对照回答
  • 可加裁判模型评高下
🗣️

辩论 Debate

立论→反驳→总结

  • 多模型多轮互相反驳
  • 可调辩论轮数
  • 主持人模型最后总结裁定

接入 · 模型与能力

🔌

多家模型

自带 Key,随意混搭

  • OpenAI 兼容:GPT / DeepSeek / GLM / Qwen / Moonshot / OpenRouter…
  • Anthropic Claude(扩展思考 · 提示缓存)
  • Google Gemini · 本地 CLI(claude/gemini/codex)
  • 每个 provider 可配模型 / 温度 / top-p / 最大 tokens
🌐

联网搜索

Firecrawl 实时检索

  • 回答带来源,正文 [n] 角标可点跳原文
  • 可抓取网页正文进上下文
📚

知识库 / 本地 RAG

全程离线 · 零成本

  • Apple 句向量 + BM25 混合检索
  • 绑定资料夹,发送时按问题检索注入
🖼️

视觉 / 出图 / 附件

不止文字

  • 图片识图 · 图像生成
  • 拖拽文件 / PDF 当附件
  • macOS 工作目录:注入内容 + 写回文件

工作流 · 研究 Agent 交付

🔎

深度研究

搜索→抓取→提炼→自查

  • 自动多轮联网搜索、抓取正文、提炼要点
  • 生成带引用角标和参考来源的结构化长报告
  • 过程实时可见,可随时停止或转成交付物
🧭

Agent 运行中心

长任务有记录、有回放

  • 记录任务步骤、工具调用、模型、耗时和成本
  • 支持搜索 / 筛选 / 审批 / 重跑
  • 任意步骤可复制 Markdown 回放或分叉继续
  • AI 待办收件箱聚合审批、失败、运行中和记忆提醒
📦

交付物工作台

把回答变成可交付文件

  • 回答、研究、会议可一键整理成 Markdown / HTML / 网页
  • 导出 Word / PPTX / PDF 真文件
  • 可发布到 GitHub Pages 生成分享链接
📋

会议闭环

会前、会中、会后连起来

  • 从日历会议生成议程和准备材料
  • 双轨捕获系统声音 + 麦克风并生成纪要
  • 自动提炼决策、风险、行动项和跟进草稿

日常 · 管理与效率

🗂️

对话管理

井井有条

  • 文件夹 / 标签 / 置顶 / 回收站(可恢复)
  • 草稿自动保存 · 接续生成 / 重答 / 编辑某轮
  • 每会话独立系统提示 + 生成参数(温度/top-p/最大tokens)
⌨️

效率工具

键盘流

  • 命令面板 ⌘K:跳会话 / 切模式 / 切模型
  • 跨会话全局搜索(直达命中那一轮)
  • 提示词库({{变量}}) · 场景模板 · 收藏夹
  • 每行面板数可调 · 追问建议
🔊

语音 / 朗读

解放双手

  • TTS 逐字高亮朗读(讯飞 + 神经语音)
  • 语音对话模式(免手连续对话)
  • 听写输入
💰

成本 / 用量

花得明白

  • Token 统计(按天/模型 · 成本估算 · 缓存命中)
  • 月度预算上限 + 发送前超支告警

可信 · 个性化与扩展

🛡️

回答可信度

事实句绑定来源

  • 一键分析回答里的事实句是否有来源支撑
  • 输出可信度分数、证据缺口和来源覆盖统计
  • 适合研究报告、行业判断和重要决策前复核
  • 记忆审计检查长期记忆来源、重复、过期和 Persona 归属
🩺

模型体检 / 路由

配置坏了能定位,模型好坏能学习

  • 批量检查 Base URL、API Key、CLI 命令和延迟
  • 盲测积累个人模型偏好,按任务类别推荐
  • 省钱级联:便宜模型先答,不达标再升级
🎯

分歧 / 红队 / 接力

不只生成答案,还会拆答案

  • 分歧雷达找出多模型真正不一致的点
  • 红队压测专挑幻觉、弱论断和无出处数据
  • 接力精炼:起草、批判、润色跨厂商流水线
🧩

连接器 / MCP / 技能包

把 Kown 接进外部工具链

  • 连接器中心统一看 GitHub、Firecrawl、MCP、日历等状态
  • Kown MCP Server 让外部 AI 工具读取会话和长期记忆
  • .kownskill 技能包可导入、导出、预览权限和变量
  • 流程模板市场一键安装调研、会议、红队、竞品和代码审查流水线
